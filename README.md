# Wolfenslop

Wolfenslop is a game about overthrowing proprietary monopolies through the power of open source.

## Current State

Wolfenslop is currently only a simple demo running on top of my raycasting engine.

## How to install

Go to the Github releases and download the Linux x86_64 build of the game (more operating systems and architectures coming soon). Then mark the binary as executable and run it.

## How to play

You can use WASD to move and you can move the mouse to aim.

## Troubleshooting

### Unable to find a GPU!

Make sure to install the Vulkan drivers. On Arch Linux, you can do this using `sudo pacman -S vulkan-intel` for Intel graphics cards or `sudo pacman -S vulkan-radeon` for AMD graphics cards.
